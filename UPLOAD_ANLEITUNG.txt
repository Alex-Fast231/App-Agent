FaSt-Doku – Vollständiger App-Stand für ein neues GitHub-Repo
================================================================
Stand: 2026-08-22, sechste Session (8 vorgegebene Aufgaben komplett
umgesetzt), Version 3.9.27

Diese ZIP enthält den KOMPLETTEN, lauffähigen und getesteten Stand der
App (alle 34 Dateien), direkt aus der getesteten Arbeitsumgebung
exportiert. Kein Zusammenfügen mit älteren ZIPs nötig – einfach diese
verwenden.

Der Viewer wird wie gewünscht separat als eigene Datei bereitgestellt
(FaSt-Doku-Viewer-v2.zip) - diese ZIP hier ist die Haupt-App. Der
Vollständigkeit halber ist viewer/ trotzdem auch in dieser kompletten
App-ZIP enthalten, da er Teil desselben Repos ist.

So laden Sie ein neues GitHub-Repo hoch
------------------------------------------
Option A – über die GitHub-Weboberfläche (am einfachsten):
1. Auf github.com ein neues, leeres Repository anlegen (KEIN README,
   .gitignore oder Lizenz beim Anlegen auswählen).
2. Im neuen Repo auf "uploading an existing file" klicken.
3. Alle Dateien/Ordner aus dieser ZIP (entpackt) per Drag & Drop
   hochladen. Achtung: der versteckte Ordner ".githooks" wird von
   manchen Datei-Explorern nicht angezeigt – ggf. "versteckte Dateien
   anzeigen" aktivieren (nicht zwingend nötig für den Betrieb der App
   selbst, nur für die automatische Versionsnummer-Erhöhung bei
   künftigen lokalen Commits relevant).
4. Commit direkt im Browser bestätigen.

Option B – über die Kommandozeile (falls git installiert ist):
    cd <entpackter-ordner-dieser-zip>
    git init
    git add -A
    git commit -m "Initial commit"
    git branch -M main
    git remote add origin https://github.com/<IHR-NUTZERNAME>/<REPO-NAME>.git
    git push -u origin main

Nach dem Hochladen (nur bei Option B relevant, für zukünftige lokale
Weiterentwicklung mit automatischer Versionserhöhung):
    git config core.hooksPath .githooks

Wenn Sie stattdessen ein BESTEHENDES Repo aktualisieren möchten:
einfach alle Dateien aus dieser ZIP über die bestehenden Dateien im
Repo kopieren/hochladen (überschreiben) und committen. Achtung: der
Ordner "vendor/tesseract" und die Datei "modules/ocr.js" existieren in
dieser Version nicht mehr (Kamera/OCR wurde komplett entfernt) – falls
sie in Ihrem bestehenden Repo noch vorhanden sind, bitte manuell
löschen.

Neu in dieser Version (gegenüber der letzten ZIP) – die 8 Aufgaben
----------------------------------------------------------------------
1. OCR/Kamera komplett entfernt – nur noch manuelle Eingabe beim
   Anlegen von Patient + Rezept.
2. Arzt-Autocomplete: Beim Tippen im Arzt-Feld erscheint jetzt
   zuverlässig ein Dropdown mit passenden, bereits gespeicherten
   Ärzten; Auswahl füllt Adresse/PLZ/Ort automatisch aus.
3. Automatische Punktsetzung funktioniert jetzt auch beim zweiten
   ICD-10-Feld.
4. Der tägliche automatische Backup-Versand prüft jetzt nach
   Kalendertagen (Mitternacht), nicht mehr nach vollen 24 Stunden seit
   dem letzten Versand. Kurzer Hinweis "Daten abgeschickt" nach
   erfolgtem Versand (nur für den aktuellen Testbetrieb).
5. Im Assessment-Einstieg gibt es jetzt einen Button "Letztes
   Assessment ansehen", falls für den Patienten bereits eines
   durchgeführt wurde.
6. Therapiebericht überarbeitet: automatische Einleitung mit
   Patientendaten, alle bisherigen Assessments statt nur des letzten,
   zwei neue Fragen (Therapie weiterführen? / Nutzen?), und ein
   Schnellzugriff-Button "Arztbericht" direkt in der Patientenliste.
   Dafür neues Patientenfeld "Anrede" beim Anlegen.
7. Viewer überarbeitet (siehe separate FaSt-Doku-Viewer-v2.zip): PIN-
   Sperre beim Öffnen, neue Tabs "Kilometer" und "Abgabelisten".
8. App-Name im Header von "FaSt-Doku" auf "FaSt App" geändert.

Details siehe HANDOFF_SUMMARY.md, Abschnitt "6".
